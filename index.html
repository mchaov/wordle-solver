How scores work

Each rule has its own scale. Higher scores rank first within a column. Bold values mark that rule’s top 15.

Coverage · Score 1
Favors guesses that test several common letters. Each distinct unconfirmed letter earns points for how often it occurs in the remaining matches.
Language · Score 2
Adds the language-wide frequency weight of every letter in the guess, including repeated letters.
All letters · Score 3
Uses the same frequencies as Coverage, counting each copy of an unconfirmed letter. A double letter earns its points twice.
